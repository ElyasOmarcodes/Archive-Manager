# د نمونې آرشیف جوړول

د پروګرام د ازموینې لپاره یو فرضي آرشیف جوړوي — زرګونه پیښې، ریښتیني
(خو ډېر کوچني) ضمیمې، او درې‌ګوني تقویمونه.

## چلول

```bash
# ۱) مېډیا حوض (یو ځل بس دی — پخوا جوړ شوی په tool/sample-media کې دی)
./tool/make_sample_media.sh tool/sample-media

# ۲) آرشیف جوړول
MEDIA=tool/sample-media OUT=/tmp/Arvitch-Sample COUNT=3000 HTML=300 \
  flutter test tool/make_sample_archive.dart

# ۳) کمپرس
cd /tmp && zip -r -9 Arvitch-Sample.zip Arvitch-Sample
```

## متغیرې

| متغیر | معنا | ډیفالټ |
|---|---|---|
| `MEDIA` | د مېډیا حوض فولډر | — (اړین) |
| `OUT` | چېرته جوړ شي | — (اړین) |
| `COUNT` | د پیښو شمېر | `3000` |
| `HTML` | څو یې `index.html` هم ولري | `300` |

## ولې ټول `index.html` نه لري؟

`index.html` هره یوه ~۱۴KB ده. د ۳,۰۰۰ پیښو لپاره دا ۴۲MB کیږي، خو
پروګرام یې د هرې پیښې د **ثبت** پر مهال پخپله بیا جوړوي — او د
پروګرام دننه پریویو له `metadata.json` څخه کار کوي، نه له HTML څخه.
نو د ټولو ۳,۰۰۰ پیښو پریویو کار کوي.

## د تصادف تخم

تخم ثابت دی (`Random(20260905)`)، نو هر ځل **دقیقاً هماغه** آرشیف
جوړیږي — د ازموینو د بیا تکرار لپاره.
